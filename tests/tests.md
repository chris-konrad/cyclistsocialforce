# Tests

This directory contains tests for particular functions of the package implemented as manual tests.

## Vizualisation

### test_BalancingRiderDrawing.py

This test verifies the 2D animation of the `BalancingRiderBicycle`
model with `BalancingRiderDrawing` representing roll/steer of the bicycle
in brids-eye projection.

Intended for:
- Visual inspection of the `BalancingRiderDrawing`
- Checking animation behavior
- Checking model behavior
